# 10: PDF คำขอถอนเงิน

**What to build:** เมื่อคำขอถอนเงินเข้าสถานะ อนุมัติ ระบบสร้าง PDF ที่มีหน้าตาตามแบบฟอร์มถอนเงินของสหกรณ์ ใส่ข้อมูลคำขอ บัญชีรับเงิน และลายมือชื่อของสมาชิกทั้งในช่องเจ้าของบัญชีและช่องผู้รับเงิน แล้วเจ้าหน้าที่เปิดดูหรือพิมพ์จากหน้าเว็บได้

**Blocked by:** 09 - คำขอถอนเงิน

**Status:** done ยกเว้นการตรวจ PDF จริงบนชุดทดสอบ ต้นแบบเริ่มต้นปรับตามแบบฟอร์ม "ใบถอนเงินออนไลน์" ของสหกรณ์แล้ว (ไฟล์ แบบฟอร์มถอนเงิน.pdf)

**ปรับตามแบบฟอร์มของสหกรณ์:**

- [x] หัวกระดาษมีตราสหกรณ์ ชื่อสหกรณ์ และ "ใบถอนเงินออนไลน์" จัดช่องตามแบบฟอร์ม บน A4 หน้าเดียว
- [x] ประเภทบัญชีแบบเลือก (● ที่ประเภทของบัญชี ○ ที่อีกช่อง)
- [x] ช่องสาขาของบัญชีรับเงิน: สมาชิกกรอกตอนลงทะเบียนบัญชีรับเงิน (บัญชีเดิมเว้นว่าง)
- [x] ช่องหมายเลขโทรศัพท์ติดต่อกลับ: สมาชิกกรอกตอนถอนเงิน เติมจากครั้งล่าสุดให้ เจ้าหน้าที่เห็นในหน้ารายละเอียดคำขอ
- [x] ช่องสำหรับเจ้าหน้าที่สหกรณ์: เส้นลงนามว่าง ใต้เส้นพิมพ์ชื่อผู้ตรวจ (เจ้าหน้าที่) และผู้อนุมัติ (ผู้จัดการ)
- [x] แนบสำเนาบัตรประชาชน สมุดบัญชีสหกรณ์ และสมุดบัญชีธนาคารจากเอกสารของบัญชีรับเงิน (ไฟล์ PDF แทนด้วยข้อความ) พร้อมหมายเหตุและเบอร์โทรของสหกรณ์
- [x] ผู้ดูแลระบบกด "สร้างต้นแบบใหม่ตามแบบฟอร์มสหกรณ์" ได้ (ต้นแบบเดิมเปลี่ยนชื่อเป็นเลิกใช้ ไม่ลบ)

**เดิม:**

- [x] Google Docs ต้นแบบมีตัวแทน (placeholder) สำหรับเลขที่คำขอ, วันที่, หมายเลขบัญชี, ชื่อบัญชี, ประเภทบัญชี, ยอดเงินทั้งตัวเลขและตัวอักษรภาษาไทย, ข้อมูลบัญชีรับเงิน และลายมือชื่อ 2 ช่อง
- [x] ถ้ายังไม่ได้แบบฟอร์มกระดาษของสหกรณ์ ให้ใช้ต้นแบบชั่วคราวที่มีช่องครบ และระบุในหน้าตั้งค่าว่าเป็นต้นแบบชั่วคราว
- [x] ที่เก็บไฟล์สร้าง PDF จากสำเนาของต้นแบบ บันทึกในโฟลเดอร์ PDF (ตั้งชื่อตามเลขที่คำขอ) ลบสำเนา Docs ทิ้ง แล้วเก็บรหัสไฟล์ไว้ในคำขอ
- [x] สร้าง PDF ไม่สำเร็จแล้วการอนุมัติต้องไม่ล้มเหลว แต่บันทึก audit log และมีปุ่ม "สร้าง PDF ใหม่" ในหน้าเว็บ
- [x] หน้ารายละเอียดคำขอมีปุ่มเปิด PDF ผ่าน `viewDocument`
- [x] การทดสอบที่ตัวรับคำสั่งครอบคลุม (ใช้ที่เก็บไฟล์ปลอม): อนุมัติแล้วมีการสร้าง PDF, สร้างไม่สำเร็จแล้วการอนุมัติยังสำเร็จ, การแปลงยอดเงินเป็นตัวอักษรภาษาไทย
- [ ] ตรวจด้วยมือบนชุดทดสอบ: push โค้ดใหม่ กด "สร้างต้นแบบใหม่ตามแบบฟอร์มสหกรณ์" แล้วอนุมัติคำขอถอนเงินทดลองหนึ่งรายการ ดูว่า PDF อยู่ในหน้าเดียว ตราสหกรณ์ ภาษาไทย ลายมือชื่อ และรูปเอกสารแนบถูกต้อง
