# 03: นำเข้าข้อมูลบัญชีเงินฝาก

**What to build:** ผู้ดูแลระบบอัปโหลดไฟล์ .xlsx ที่ export จากระบบหลักผ่านหน้าเว็บเจ้าหน้าที่ แล้วระบบแทนที่ตารางบัญชีเงินฝากทั้งตาราง ถ้าไฟล์ผิดแม้แถวเดียว ระบบปฏิเสธทั้งไฟล์ แจ้งเลขแถวที่ผิด และข้อมูลเดิมไม่เปลี่ยน

**Blocked by:** 02 - เจ้าหน้าที่เข้าระบบและจัดการบัญชีเจ้าหน้าที่

**Status:** done (ทดสอบผ่านตัวรับคำสั่งและหลังบ้านจำลองด้วย CSV แล้ว ยังไม่ได้ทดสอบการแปลง .xlsx ผ่าน Drive จริง)

- [x] `importAccounts` (ผู้ดูแลระบบเท่านั้น) รับไฟล์ .xlsx แล้วแปลงเป็น Sheets ชั่วคราวผ่าน Drive API
- [x] ต้องมีครบทุกคอลัมน์: ลำดับ, หมายเลขบัญชี, รหัสสมาชิก, เลขบัตรประชาชน, ชื่อบัญชี, ประเภทบัญชี, ข้อมูลติดต่อล่าสุด (วันที่)
- [x] ตรวจทุกแถว: รหัสสมาชิกเติม 0 ได้ครบ 5 หลัก, เลขบัตรประชาชน 13 หลักและ checksum ถูกต้อง, ประเภทบัญชีเป็น ออมทรัพย์ หรือ ออมทรัพย์พิเศษ, หมายเลขบัญชีไม่ซ้ำ
- [x] ผิดแม้แถวเดียว ให้ตอบ error ที่ระบุเลขแถวและเหตุผลของทุกแถวที่ผิด และไม่แตะข้อมูลเดิม
- [x] ถ้าผ่าน ให้แทนที่ตารางทั้งตารางภายใต้ lock, บันทึกเวลาที่นำเข้า, บันทึก audit log และลบไฟล์ชั่วคราว
- [x] ตารางการผูกบัญชี LINE และบัญชีรับเงินไม่ถูกแตะ
- [x] หน้าเว็บมีหน้าอัปโหลด แสดงจำนวนแถวที่นำเข้า หรือรายการแถวที่ผิด
- [x] การทดสอบที่ตัวรับคำสั่งครอบคลุม: ไฟล์ถูกต้อง, คอลัมน์ขาด, แถวผิดแล้วข้อมูลเดิมไม่เปลี่ยน, การเติม 0 ให้รหัสสมาชิก
