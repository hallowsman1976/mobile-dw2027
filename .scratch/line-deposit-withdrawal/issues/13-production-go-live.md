# 13: เตรียมระบบใช้จริง

**What to build:** ตั้ง**ชุดใช้จริง**ที่แยกจากชุดทดสอบทั้งหมด จัดการความเสี่ยงจากการใช้ Gmail ส่วนตัว (ADR 0002) และทำเช็กลิสต์ก่อนเปิดให้สมาชิกใช้ ticket นี้ส่วนใหญ่เป็นงานตั้งค่าและเอกสาร ไม่ใช่ฟีเจอร์ใหม่

**Blocked by:** 01–12 ทั้งหมด

**Status:** ส่วนของโค้ดและเอกสารเสร็จแล้ว ที่เหลือเป็นงานตั้งค่าที่สหกรณ์ต้องทำเอง ตามเช็กลิสต์ใน `docs/guides/production.md` และส่วน "ความพร้อมก่อนเปิดใช้" ในหน้าเว็บเจ้าหน้าที่

ทำแล้วในโค้ด: `backend/.clasp.prod.example.json`, action `systemReadiness` กับส่วน "ความพร้อมก่อนเปิดใช้" ในหน้าเว็บเจ้าหน้าที่, `checkScriptProperties` ตรวจ SlipOK, trigger และเช็กลิสต์ความพร้อม

- [ ] ชุดใช้จริงมี LIFF app, Apps Script deployment, Spreadsheet, โฟลเดอร์ Drive และ Cloudflare Pages ของตัวเอง โดย Script Properties ตั้งค่าครบ
- [ ] แชร์ Spreadsheet, โฟลเดอร์ Drive และโปรเจกต์ Apps Script เป็น Editor ให้ Gmail ของกรรมการอีก 1 คน
- [x] มีเอกสารขั้นตอนโอนความเป็นเจ้าของ สำหรับกรณีเจ้าหน้าที่เจ้าของบัญชีลาออก
- [ ] สมัคร LINE OA แผนที่เสียเงินให้มีโควตาข้อความพอ (แผนฟรีมี 300 ข้อความต่อเดือน)
- [ ] ตั้ง Rich Menu, ข้อความต้อนรับ และนโยบายความเป็นส่วนตัวฉบับจริง
- [ ] ยืนยันระยะเวลาเก็บเอกสาร 10 ปีกับผู้สอบบัญชี และใส่ค่าในชีตตั้งค่า
- [ ] เพิ่มวันหยุดของสหกรณ์ตลอดปี และสร้างบัญชีเจ้าหน้าที่จริง (ต้องมีผู้ตรวจหรือผู้อนุมัติอย่างน้อย 2 คน)
- [ ] นำเข้าข้อมูลบัญชีเงินฝากจริงครั้งแรก
- [ ] ทดสอบรอบสุดท้ายบนชุดใช้จริงด้วยบัญชีของเจ้าหน้าที่: ผูกบัญชี LINE, ลงทะเบียนบัญชีรับเงิน, ฝาก 100 บาทด้วยสลิปจริง, ถอน 1,000 บาทผ่านการตรวจและอนุมัติ, export และปิดคำขอ
- [x] มีคู่มือสั้นสำหรับเจ้าหน้าที่และสำหรับสมาชิก
