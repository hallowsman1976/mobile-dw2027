# 05: ดูแล PIN และการผูกบัญชี

**What to build:** สมาชิกเปลี่ยน PIN ได้เองด้วย PIN เดิม ผู้ดูแลระบบรีเซ็ต PIN ของสมาชิกที่ถูกล็อก (สมาชิกจึงตั้ง PIN ใหม่ผ่าน LINE ได้) และยกเลิกการผูกบัญชี LINE ของสมาชิกที่เปลี่ยนบัญชี LINE (สมาชิกจึงผูกใหม่ได้)

**Blocked by:** 04 - ผูกบัญชี LINE และดูบัญชีเงินฝาก

**Status:** done (ทดสอบผ่านตัวรับคำสั่งและหน้าจอทั้งสองฝั่งกับหลังบ้านจำลองแล้ว ยังไม่ได้ทดสอบใน LINE จริง)

- [x] `changePin` ต้องใช้ PIN เดิมที่ถูกต้อง และ PIN ผิดนับรวมกับการล็อก 5 ครั้ง
- [x] มีความสามารถตรวจ PIN ที่ใช้ร่วมกันได้ (สำหรับ ticket 09) ผิดครบ 5 ครั้งให้ล็อก PIN จนกว่าผู้ดูแลระบบจะรีเซ็ต
- [x] `resetPin` (ผู้ดูแลระบบ) ล้าง PIN และปลดล็อก ครั้งต่อไปที่สมาชิกเปิด LIFF จะถูกพาไปตั้ง PIN ใหม่
- [x] `unbindLineAccount` (ผู้ดูแลระบบ) บันทึกเวลาและผู้ยกเลิก การผูกเดิมใช้ไม่ได้ทันที และรหัสสมาชิกนี้ผูกกับ LINE ใหม่ได้
- [x] ทุกการรีเซ็ตและยกเลิกการผูกบันทึก audit log
- [x] หน้าเว็บเจ้าหน้าที่มีหน้าค้นหาสมาชิกด้วยรหัสสมาชิก แสดงสถานะการผูกและการล็อก PIN พร้อมปุ่มรีเซ็ตและยกเลิกการผูก
- [x] หน้า LIFF "ข้อมูลบัญชี/เปลี่ยน PIN" ใช้งานได้
- [x] การทดสอบที่ตัวรับคำสั่งครอบคลุม: เปลี่ยน PIN สำเร็จ, PIN เดิมผิด, ล็อกเมื่อผิด 5 ครั้ง, รีเซ็ตแล้วตั้งใหม่ได้, ยกเลิกการผูกแล้วผูก LINE ใหม่ได้
