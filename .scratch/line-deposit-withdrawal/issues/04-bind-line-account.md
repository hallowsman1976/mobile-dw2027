# 04: ผูกบัญชี LINE และดูบัญชีเงินฝาก

**What to build:** สมาชิกเปิด LINE OA แล้วกดปุ่มใดก็ได้ใน Rich Menu ถ้ายังไม่ผูกบัญชี จะไปหน้า**การผูกบัญชี LINE** เพื่อกรอกรหัสสมาชิกและเลขบัตรประชาชน กดยินยอมนโยบายความเป็นส่วนตัว และตั้ง PIN 6 หลัก หลังผูกแล้ว สมาชิกเห็นรายการบัญชีเงินฝากของตนเอง (เลขบัญชี ชื่อ และประเภท) และครั้งต่อไปเข้าใช้ได้ทันที

**Blocked by:** 03 - นำเข้าข้อมูลบัญชีเงินฝาก

**Status:** ready-for-agent

- [ ] รหัสสมาชิกตัดช่องว่าง รับเฉพาะตัวเลข 1–5 หลัก แล้วเติม 0 ข้างหน้าให้ครบ 5 หลัก ถ้าเกิน 5 หลักหรือมีอักขระอื่นให้ปฏิเสธ
- [ ] `bindLineAccount` ผูกได้เมื่อรหัสสมาชิกและเลขบัตรประชาชนตรงกับบัญชีเงินฝากอย่างน้อย 1 แถว และบันทึกเวอร์ชันนโยบายกับเวลาที่ยินยอม
- [ ] ปฏิเสธเมื่อรหัสสมาชิกถูกผูกกับ LINE userId อื่นอยู่แล้ว (ให้ติดต่อสหกรณ์) หรือ LINE userId นี้ผูกกับสมาชิกคนอื่นอยู่แล้ว
- [ ] ผูกผิดเกิน 5 ครั้งต่อ LINE userId ภายใน 1 ชั่วโมง ให้ล็อก 1 ชั่วโมง
- [ ] `setPin` ตั้ง PIN 6 หลัก เก็บเป็น SHA-256 ผสม salt วนแฮช 10,000 รอบ
- [ ] `me` และ `listMyAccounts` คืนข้อมูลสมาชิกและบัญชีเงินฝากของตนเองเท่านั้น และไม่แสดงบัญชีที่ไม่อยู่ในข้อมูลที่นำเข้าล่าสุด
- [ ] หน้า LIFF มีหน้ายินยอม PDPA, หน้าผูกบัญชี, หน้าตั้ง PIN และหน้ารายการบัญชีเงินฝาก
- [ ] มี Rich Menu 6 ปุ่ม (ฝากเงิน · ถอนเงิน · ประวัติคำขอ · บัญชีรับเงินของฉัน · ข้อมูลบัญชี/เปลี่ยน PIN · ติดต่อสหกรณ์) ทุกปุ่มเปิด LIFF ไปยังหน้าที่ตรงกัน ปุ่มที่ฟีเจอร์ยังไม่เสร็จให้แสดง "เร็ว ๆ นี้"
- [ ] การทดสอบที่ตัวรับคำสั่งครอบคลุม: ผูกสำเร็จ, เลขบัตรไม่ตรง, ผูกซ้ำทั้งสองทิศทาง, ล็อกเมื่อผิดเกิน 5 ครั้ง, เห็นเฉพาะบัญชีของตนเอง
