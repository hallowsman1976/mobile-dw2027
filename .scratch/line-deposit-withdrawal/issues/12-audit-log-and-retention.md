# 12: audit log และการลบเอกสารเมื่อครบ 10 ปี

**What to build:** ผู้ดูแลระบบเปิดดู audit log ว่าใครเปิดดูเอกสารใด และใครเปลี่ยนสถานะอะไรเมื่อไร โดยค้นหาตามช่วงวันที่ ผู้กระทำ หรือเลขที่คำขอได้ ระบบลบเอกสาร สลิป ลายมือชื่อ และ PDF ของคำขอและบัญชีรับเงินที่ปิดไปแล้วเกิน 10 ปีโดยอัตโนมัติทุกเดือน

**Blocked by:** 09 - คำขอถอนเงิน

**Status:** done ยกเว้นการตรวจ trigger จริงบนชุดทดสอบ

- [x] `listAuditLog` (ผู้ดูแลระบบ) กรองตามช่วงวันที่ ผู้กระทำ และเป้าหมาย พร้อมแบ่งหน้า
- [x] หน้าเว็บมีหน้า audit log
- [x] trigger รายเดือนลบไฟล์ของคำขอที่ เสร็จสิ้น / ปฏิเสธ / ยกเลิก และบัญชีรับเงินที่ ปฏิเสธ / เลิกใช้ ที่ปิดไปแล้วเกิน 10 ปี (ระยะเวลาเป็นค่าในชีตตั้งค่า) โดยแถวข้อมูลยังอยู่ แต่บันทึกว่าลบไฟล์แล้ว
- [x] การลบแต่ละครั้งบันทึก audit log และ trigger ทำงานเป็นชุดเล็ก ๆ ไม่ให้เกินเวลา 6 นาทีของ Apps Script
- [x] ห้ามลบไฟล์ของบัญชีรับเงินที่ยังมีสถานะ อนุมัติ
- [x] การทดสอบที่ตัวรับคำสั่งครอบคลุม (ใช้นาฬิกาปลอม): ลบเฉพาะรายการที่เกินกำหนด, ไม่ลบบัญชีรับเงินที่ยังใช้งาน, ผู้ที่ไม่ใช่ผู้ดูแลระบบดู audit log ไม่ได้
- [ ] ตรวจด้วยมือบนชุดทดสอบ: รัน `installDocumentRetentionTrigger` แล้วรัน `runDocumentRetention` จาก editor ดูว่าไม่มี error (ข้อมูลทดสอบยังไม่ครบ 10 ปีจึงไม่ควรลบอะไร)
