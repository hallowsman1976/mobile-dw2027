# 02: เจ้าหน้าที่เข้าระบบและจัดการบัญชีเจ้าหน้าที่

**What to build:** เจ้าหน้าที่ล็อกอินเข้าหน้าเว็บเจ้าหน้าที่ด้วยชื่อผู้ใช้และรหัสผ่าน แล้วใช้งานได้ตามบทบาท (ผู้ตรวจ / ผู้อนุมัติ / ผู้ดูแลระบบ มีได้หลายบทบาท) ผู้ดูแลระบบสร้าง ปิด และรีเซ็ตรหัสผ่านเจ้าหน้าที่ได้ และมีฟังก์ชันตั้งต้นสำหรับสร้างผู้ดูแลระบบคนแรก

**Blocked by:** 01 - โครงระบบขั้นต่ำที่ทำงานได้

**Status:** ready-for-agent

- [ ] `staffLogin` ตรวจรหัสผ่านที่เก็บเป็น SHA-256 ผสม salt ของแต่ละคน วนแฮช 10,000 รอบ แล้วคืน session token แบบสุ่มอายุ 8 ชั่วโมง ซึ่งเก็บใน CacheService
- [ ] รหัสผ่านผิด 5 ครั้งล็อกบัญชี 15 นาที, บัญชีที่ปิดแล้วล็อกอินไม่ได้ และรหัสผ่านต้องยาวอย่างน้อย 10 ตัวอักษร
- [ ] `staffLogout` ทำให้ token ใช้ไม่ได้ทันที
- [ ] action ของเจ้าหน้าที่ตรวจ token และบทบาทก่อนทุกครั้ง ถ้าไม่มีสิทธิ์ให้ตอบ error ภาษาไทย
- [ ] `manageStaff` (ผู้ดูแลระบบเท่านั้น): สร้าง, ปิดหรือเปิดใช้, กำหนดบทบาท และรีเซ็ตรหัสผ่าน
- [ ] มีฟังก์ชันตั้งต้นที่รันจาก editor ของ Apps Script เพื่อสร้างผู้ดูแลระบบคนแรก
- [ ] หน้าเว็บเจ้าหน้าที่มีหน้าล็อกอิน, หน้าจัดการเจ้าหน้าที่ และกลับไปหน้าล็อกอินเมื่อ session หมดอายุ
- [ ] การทดสอบที่ตัวรับคำสั่งครอบคลุม: ล็อกอินสำเร็จ, รหัสผ่านผิด, ล็อกเมื่อผิด 5 ครั้ง, token หมดอายุ, ไม่มีบทบาทที่ต้องใช้
