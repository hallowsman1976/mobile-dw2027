# คู่มือสมาชิก: ฝากถอนเงินผ่าน LINE

สหกรณ์ออมทรัพย์สาธารณสุขจังหวัดมุกดาหาร จำกัด

ระบบนี้ใช้**ยื่นคำขอ** เจ้าหน้าที่จะตรวจและดำเนินการให้ในวันทำการ คำขอที่ยื่นหลัง 15:30 หรือวันหยุด ดำเนินการในวันทำการถัดไป ทุกขั้นตอนท่านจะได้ข้อความแจ้งใน LINE

## เริ่มใช้ครั้งแรก

1. เพิ่มเพื่อน LINE ของสหกรณ์ แล้วกดเมนูใดก็ได้
2. อ่านนโยบายความเป็นส่วนตัว แล้วกดยอมรับ
3. กรอกรหัสสมาชิก (ไม่ต้องใส่ 0 ข้างหน้า) และเลขบัตรประชาชน 13 หลัก
4. ตั้ง PIN 6 หลัก ใช้ยืนยันทุกครั้งที่ถอนเงิน ห้ามบอก PIN แก่ผู้อื่น รวมถึงเจ้าหน้าที่

## ลงทะเบียนบัญชีรับเงิน (ก่อนถอนครั้งแรก)

เมนู **บัญชีรับเงินของฉัน** → เลือกธนาคาร กรอกเลขบัญชีและชื่อบัญชี (ต้องเป็นบัญชีของท่านเอง) แนบภาพ 3 อย่าง:

- สำเนาบัตรประชาชน
- สำเนาบัญชีเงินฝากสหกรณ์
- สำเนาหน้าสมุดบัญชีรับเงิน

รอเจ้าหน้าที่ตรวจ เมื่ออนุมัติแล้วจะได้ข้อความแจ้ง ลงทะเบียนครั้งเดียวใช้ได้ตลอด

## ฝากเงิน

1. โอนเงินเข้าบัญชีกรุงไทยของสหกรณ์ เก็บสลิปไว้
2. เมนู **ฝากเงิน** → เลือกบัญชีเงินฝาก เลือกวันเวลาที่โอน กรอกจำนวนเงิน (ขั้นต่ำ 100 บาท) แนบภาพสลิป (ไม่เกิน 5 MB)
3. ระบบอ่านสลิปให้ ถ้ายอดหรือเวลาไม่ตรงกับที่กรอก ให้ตรวจอีกครั้งก่อนยืนยัน
4. ส่งคำขอ เจ้าหน้าที่จะบันทึกเข้าบัญชีในวันทำการ

## ถอนเงิน

1. เมนู **ถอนเงิน** → เลือกบัญชีเงินฝาก กรอกจำนวนเงิน 1,000–100,000 บาท เลือกบัญชีรับเงิน
2. เซ็นชื่อบนหน้าจอ แล้วกรอก PIN
3. คำขอผ่านการตรวจและอนุมัติแล้ว สหกรณ์จะโอนเงินในวันทำการ

ยื่นคำขอถอนเงินค้างได้ครั้งละหนึ่งรายการต่อบัญชีเงินฝาก

## ดูสถานะและยกเลิก

เมนู **ประวัติคำขอ** แสดงสถานะ: รอตรวจ, รออนุมัติ, อนุมัติ, เสร็จสิ้น, ปฏิเสธ (พร้อมเหตุผล), ยกเลิก ยกเลิกเองได้เฉพาะตอนรอตรวจ

## ปัญหาที่พบบ่อย

| ปัญหา | ทำอย่างไร |
|---|---|
| ผูกบัญชีไม่ได้ | ตรวจรหัสสมาชิกและเลขบัตร ถ้ากรอกผิด 5 ครั้งต้องรอ 1 ชั่วโมง หรือติดต่อสหกรณ์ |
| ลืม PIN หรือ PIN ถูกล็อก (ผิด 5 ครั้ง) | ติดต่อสหกรณ์เพื่อรีเซ็ต แล้วตั้ง PIN ใหม่ใน LINE |
| เปลี่ยนโทรศัพท์หรือบัญชี LINE | ติดต่อสหกรณ์เพื่อยกเลิกการผูกบัญชีเดิม แล้วผูกใหม่ |
| เปลี่ยน PIN | เมนู **ข้อมูลบัญชี / เปลี่ยน PIN** |
| ไม่เห็นบัญชีเงินฝากที่เพิ่งเปิด | รอสหกรณ์ปรับปรุงข้อมูล หรือติดต่อสหกรณ์ |

สหกรณ์ไม่เคยขอ PIN หรือรหัส OTP ทางโทรศัพท์หรือข้อความ ติดต่อสหกรณ์ได้ที่เมนู **ติดต่อสหกรณ์**
