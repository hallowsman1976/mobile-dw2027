# 11: export รายวันและปิดคำขอ

**What to build:** เจ้าหน้าที่เลือกวันทำการ แล้ว export คำขอที่อยู่ในสถานะ อนุมัติ ของวันนั้นเป็นไฟล์ .xlsx (แยกแท็บฝากและถอน) เพื่อนำไปบันทึกในระบบหลักและโอนเงินผ่าน KTB Corporate Online เมื่อทำเสร็จ ก็ปิดคำขอเป็น เสร็จสิ้น ได้ทีละรายการหรือทั้งชุด สมาชิกได้ข้อความแจ้ง

**Blocked by:** 07 - คำขอฝากเงิน, 09 - คำขอถอนเงิน

**Status:** done (ทดสอบผ่านตัวรับคำสั่งและหน้าจอกับหลังบ้านจำลองแล้ว ยังไม่ได้ทดสอบการสร้าง .xlsx ผ่าน Google Sheets จริง; export รวมรายการค้างที่วันทำการไม่เกินวันที่เลือก)

- [x] `exportApproved` รับวันทำการ แล้วคืนไฟล์ .xlsx ที่มีแท็บ ฝาก (เลขที่คำขอ, หมายเลขบัญชี, ชื่อบัญชี, ยอด, วันเวลาโอน, ผลตรวจสลิป) และแท็บ ถอน (เลขที่คำขอ, หมายเลขบัญชี, ชื่อบัญชี, ยอด, ธนาคาร, เลขบัญชีรับเงิน, ชื่อบัญชีรับเงิน)
- [x] การ export ไม่เปลี่ยนสถานะคำขอ และบันทึก audit log
- [x] `completeRequests` รับรายการเลขที่คำขอ เปลี่ยนได้เฉพาะคำขอในสถานะ อนุมัติ และคืนผลแยกตามรายการว่ารายการไหนสำเร็จหรือล้มเหลวพร้อมเหตุผล
- [x] คำขอที่เสร็จสิ้นบันทึกผู้ปิดและเวลา แจ้งสมาชิก และไม่นับเป็นคำขอค้างอีก
- [x] หน้าเว็บมีหน้า "งานประจำวัน" ที่เลือกวันทำการ, ดาวน์โหลดไฟล์, เลือกหลายรายการแล้วปิดพร้อมกัน
- [x] การทดสอบที่ตัวรับคำสั่งครอบคลุม: export เฉพาะสถานะ อนุมัติ ของวันที่เลือก, ปิดทั้งชุดที่มีรายการผิดสถานะปนอยู่, ปิดแล้วยื่นคำขอถอนเงินใหม่ในบัญชีเดียวกันได้
