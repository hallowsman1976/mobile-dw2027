# 09: คำขอถอนเงิน

**What to build:** สมาชิกยื่น**คำขอถอนเงิน**ผ่าน LIFF โดยเลือกบัญชีเงินฝาก (เติมข้อมูลให้อัตโนมัติ) และบัญชีรับเงินที่อนุมัติแล้ว กรอกยอด 1,000–100,000 บาท เซ็นลายมือชื่อบนจอครั้งเดียว และยืนยันด้วย PIN จากนั้นผู้ตรวจส่งต่อให้ผู้อนุมัติ ซึ่งต้องเป็นคนละคนกัน แล้วผู้อนุมัติอนุมัติหรือปฏิเสธ สมาชิกได้ข้อความแจ้งทุกครั้งที่สถานะเปลี่ยน

**Blocked by:** 06 - บัญชีรับเงิน และการแจ้งเตือนผ่าน LINE, 07 - คำขอฝากเงิน

**Status:** done (ทดสอบผ่านตัวรับคำสั่งและหน้าจอทั้งสองฝั่งกับหลังบ้านจำลองแล้ว ยังไม่ได้ทดสอบใน LINE จริง)

- [x] `submitWithdrawalRequest`:
  - บัญชีเงินฝากต้องเป็นของสมาชิกและอยู่ในข้อมูลที่นำเข้าล่าสุด
  - บัญชีรับเงินต้องเป็นของสมาชิกและมีสถานะ อนุมัติ
  - ยอดต้องอยู่ระหว่าง 1,000–100,000 บาท
  - ต้องมีลายมือชื่อเป็นภาพ PNG (บันทึกลง Drive)
  - PIN ต้องถูกต้อง (ใช้การตรวจ PIN จาก ticket 05) และนับการล็อก
- [x] บัญชีเงินฝากที่มี**คำขอค้าง**ประเภทถอนอยู่แล้ว ยื่นใหม่ไม่ได้ (ตรวจภายใต้ lock)
- [x] เลขที่คำขอ `WD-<ปี>-<ลำดับ>` และคำนวณวันทำการแบบเดียวกับคำขอฝากเงิน
- [x] ลำดับสถานะ: รอตรวจ → รออนุมัติ (`reviewRequest` โดยผู้ตรวจ) → อนุมัติ (`approveRequest` โดยผู้อนุมัติ) ทั้งสองขั้นปฏิเสธได้โดยต้องมีเหตุผล และยกเลิกได้เฉพาะตอน รอตรวจ
- [x] ผู้อนุมัติต้องไม่ใช่คนเดียวกับผู้ตรวจของคำขอนั้น แม้คนนั้นจะมีทั้งสองบทบาท
- [x] แจ้งกลุ่มเจ้าหน้าที่เมื่อมีคำขอใหม่ และเมื่อคำขอเข้า รออนุมัติ
- [x] หน้าเว็บมีรายละเอียดคำขอถอนเงินที่แสดงลายมือชื่อ และลิงก์ไปเอกสารของบัญชีรับเงิน รวมทั้งคิว "รออนุมัติ" สำหรับผู้อนุมัติ
- [x] หน้า LIFF ถอนเงินมี signature pad (ล้างแล้ววาดใหม่ได้) และหน้ายืนยัน PIN
- [x] การทดสอบที่ตัวรับคำสั่งครอบคลุม: ยื่นสำเร็จ, ยอดนอกช่วง, คำขอค้างซ้ำ, บัญชีรับเงินที่ยังไม่อนุมัติหรือเป็นของคนอื่น, PIN ผิดและถูกล็อก, ผู้ตรวจอนุมัติคำขอที่ตัวเองตรวจไม่ได้, ลำดับสถานะทุกเส้นทาง, ยื่นใหม่ได้หลังคำขอเดิมถูกปฏิเสธหรือเสร็จสิ้น
