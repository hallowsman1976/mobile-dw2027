# 07: คำขอฝากเงิน (ยังไม่ตรวจสลิปอัตโนมัติ)

**What to build:** สมาชิกยื่น**คำขอฝากเงิน**ผ่าน LIFF โดยเลือกบัญชีเงินฝาก (เติมข้อมูลให้อัตโนมัติ) วันเวลาโอนจาก Flatpickr ยอดเงิน และสลิป แล้วได้เลขที่คำขอกับวันทำการที่จะดำเนินการ ผู้ตรวจอนุมัติหรือปฏิเสธบนหน้าเว็บ สมาชิกดูประวัติ ยกเลิกคำขอที่ยังรอตรวจ และได้ข้อความแจ้งทุกครั้งที่สถานะเปลี่ยน ใน ticket นี้ทุกคำขอติดผล **ยังไม่ตรวจสลิป** (การตรวจด้วย SlipOK อยู่ใน ticket 08)

**Blocked by:** 06 - บัญชีรับเงิน และการแจ้งเตือนผ่าน LINE

**Status:** ready-for-agent

- [ ] `submitDepositRequest`: บัญชีเงินฝากต้องเป็นของสมาชิก, ยอดอย่างน้อย 100 บาท, วันเวลาโอนต้องไม่อยู่ในอนาคต, สลิปเป็น JPG/PNG ไม่เกิน 5MB
- [ ] เลขที่คำขอ `DP-<ปี>-<ลำดับ>` ออกภายใต้ lock และบันทึกชื่อบัญชีกับประเภทบัญชี ณ เวลายื่น
- [ ] ลำดับสถานะของคำขอฝากเงิน: รอตรวจ → อนุมัติ → เสร็จสิ้น, ปฏิเสธ (จาก รอตรวจ ต้องมีเหตุผล) และยกเลิก (จาก รอตรวจ โดยเจ้าของคำขอเท่านั้น) การเปลี่ยนสถานะอื่นทั้งหมดถูกปฏิเสธ
- [ ] วันทำการ: ยื่นหลัง 15:30 (ค่าจากชีตตั้งค่า) หรือในวันเสาร์ อาทิตย์ หรือวันหยุด ให้ใช้วันทำการถัดไป
- [ ] `manageHolidays` (ผู้ดูแลระบบ) เพิ่มและลบวันหยุด
- [ ] `listMyRequests`, `cancelRequest`, `listRequests` (กรองตามสถานะ ประเภท และวันที่), `getRequest` และ `reviewRequest` (ผู้ตรวจ) ใช้งานได้ ส่วนสลิปเปิดดูผ่าน `viewDocument`
- [ ] แจ้งสมาชิกทุกครั้งที่สถานะเปลี่ยน แจ้งกลุ่มเจ้าหน้าที่เมื่อมีคำขอใหม่ และบันทึก audit log ทุกครั้งที่สถานะเปลี่ยน
- [ ] หน้า LIFF ฝากเงินและประวัติคำขอ, หน้าเว็บคิวคำขอและหน้ารายละเอียด และหน้าวันหยุดใช้งานได้
- [ ] การทดสอบที่ตัวรับคำสั่งครอบคลุม: ยื่นสำเร็จ, ยอดต่ำกว่า 100, เวลาในอนาคต, บัญชีของคนอื่น, ลำดับสถานะทุกเส้นทาง (รวมเส้นทางที่ไม่อนุญาต), ยกเลิกคำขอของคนอื่นไม่ได้, วันทำการ (ก่อนและหลัง 15:30, เสาร์อาทิตย์, วันหยุดติดกันหลายวัน)
