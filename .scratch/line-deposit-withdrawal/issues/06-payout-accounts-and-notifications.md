# 06: บัญชีรับเงิน และการแจ้งเตือนผ่าน LINE

**What to build:** สมาชิกลงทะเบียน**บัญชีรับเงิน** (ธนาคาร, เลขบัญชี, ชื่อบัญชี) พร้อมสำเนาบัตรประชาชน สำเนาบัญชีเงินฝาก และสำเนาบัญชีรับเงิน กลุ่ม LINE ของเจ้าหน้าที่ได้ข้อความแจ้ง จากนั้นผู้ตรวจเปิดดูเอกสารบนหน้าเว็บแล้วอนุมัติหรือปฏิเสธพร้อมเหตุผล และสมาชิกได้ข้อความแจ้งผลใน LINE ticket นี้สร้างตัวส่งข้อความตัวจริงและที่เก็บไฟล์ตัวจริงเป็นครั้งแรก

**Blocked by:** 04 - ผูกบัญชี LINE และดูบัญชีเงินฝาก

**Status:** done (ทดสอบผ่านตัวรับคำสั่งและหน้าจอทั้งสองฝั่งกับหลังบ้านจำลองแล้ว ยังไม่ได้ทดสอบการเก็บไฟล์ใน Drive และการส่งข้อความ LINE จริง)

- [x] `registerPayoutAccount` รับไฟล์ base64 3 ไฟล์ (JPG/PNG/PDF ไม่เกิน 5MB ต่อไฟล์) บันทึกลงโฟลเดอร์ Drive ที่ไม่แชร์ลิงก์ และสร้างบัญชีรับเงินสถานะ รอตรวจ
- [x] `listMyPayoutAccounts` แสดงสถานะและเหตุผลที่ปฏิเสธ ส่วน `retirePayoutAccount` เปลี่ยนสถานะเป็น เลิกใช้
- [x] `reviewPayoutAccount` (ผู้ตรวจ) อนุมัติ หรือปฏิเสธโดยต้องมีเหตุผล
- [x] `viewDocument` คืนไฟล์เป็น base64 หลังตรวจบทบาท และบันทึก audit log ทุกครั้งที่เปิด
- [x] ตัวส่งข้อความ (Messaging API push): แจ้งสมาชิกเมื่อบัญชีรับเงินถูกอนุมัติหรือปฏิเสธ และแจ้งกลุ่มเจ้าหน้าที่เมื่อมีการลงทะเบียนใหม่ (ห้ามใส่เลขบัตรประชาชนหรือเลขบัญชีเต็ม)
- [x] ส่งข้อความไม่สำเร็จแล้ว action ต้องไม่ล้มเหลว แต่บันทึกลง audit log
- [x] webhook: `doPost` ที่ไม่มี action รับเฉพาะ event `join` และบันทึก groupId ผู้ดูแลระบบเลือกกลุ่มเจ้าหน้าที่จากหน้าตั้งค่าได้
- [x] หน้า LIFF "บัญชีรับเงินของฉัน" และหน้าเว็บคิวตรวจบัญชีรับเงินใช้งานได้
- [x] การทดสอบที่ตัวรับคำสั่งครอบคลุม: ลงทะเบียน, ไฟล์ใหญ่เกินหรือชนิดไม่ถูกต้อง, อนุมัติหรือปฏิเสธพร้อมข้อความแจ้งที่ตัวส่งข้อความปลอมได้รับ, ปฏิเสธโดยไม่มีเหตุผล, ส่งข้อความไม่สำเร็จแล้ว action ยังสำเร็จ, ไม่มีบทบาทผู้ตรวจ
