# ระบบ LINE รับเฉพาะคำขอ ไม่ตัดหรือเพิ่มยอดในระบบหลัก

ระบบฝากถอนผ่าน LINE ทำหน้าที่รับคำขอถอนเงินและคำขอฝากเงิน แล้วให้เจ้าหน้าที่ตรวจ อนุมัติ และบันทึกรายการในระบบหลักของสหกรณ์ด้วยมือ ระบบไม่เขียนข้อมูลกลับไปที่ระบบหลักเลย และรับข้อมูลสมาชิกกับบัญชีเงินฝากจากไฟล์ Excel ที่เจ้าหน้าที่ export มานำเข้าเป็นระยะ เหตุผลคือการถอนเงินต้องมีคนตรวจลายมือชื่อและเอกสารอยู่แล้ว และการไม่ต้องเชื่อมต่อแบบเขียนกับระบบหลักทำให้เริ่มใช้ได้เร็ว โดยไม่ต้องพึ่งผู้ขายระบบหลัก

## Consequences

- ระบบไม่รู้ยอดคงเหลือ จึงตรวจการถอนเกินยอดไม่ได้ เจ้าหน้าที่ต้องตรวจยอดในระบบหลักก่อนอนุมัติ และแต่ละบัญชีเงินฝากมีคำขอถอนเงินค้างได้ครั้งละหนึ่งรายการ
- ข้อมูลบัญชีเงินฝากในระบบอาจไม่ทันสมัย ขึ้นกับรอบการนำเข้า
- ถ้าภายหลังระบบหลักมี API การเปลี่ยนไปตัดยอดอัตโนมัติจะกระทบทั้งลำดับสถานะคำขอและบทบาทของเจ้าหน้าที่
